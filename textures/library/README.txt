Wrzuć tu zdjęcia fasad i dachów (PNG / JPG / WebP). Każde zdjęcie staje się osobną teksturą.
Rodzaj jest zgadywany z nazwy pliku lub podfolderu:
  dach, roof, papa, blacha  -> dach
  szczyt, gable             -> ściana szczytowa
  dlugi, front, long        -> długa ściana
  drzwi / okno / komin      -> elementy (jeszcze nie układane na modelu)
  cokolwiek innego          -> elewacja (pasuje na każdą ścianę)
Przykłady: dach_papa_01.jpg, roof/lupek.png, cegla_czerwona.jpg
Zdjęcia dodane przyciskiem w programie trafiają do user://texture_library (Otwórz folder biblioteki).
